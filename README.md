### 🚀 Sobre mí

Soy ingeniero en Colombia. Trabajo en dos frentes:

- **En el sector salud** automatizo los procesos de datos de un software clínico: cargue masivo con n8n, APIs de plantillas Excel y agentes de IA para el equipo de soporte. Un proceso que tomaba **3 semanas ahora toma 2 días**.
- **En una agencia de marketing** lidero la parte de tecnología y construyo productos que usan negocios reales: reservas en línea, pedidos para restaurantes, el panel interno del equipo y un editor de video con IA.

```yaml
enfoque: backend, automatización de procesos e IA aplicada a productos
trabajo_con: .NET · Python · TypeScript · Google Apps Script · n8n · Cloudflare · Claude
ahora_mismo:
  - Migrando un sistema de escritorio (VB.NET) a web con .NET 10, Blazor y SQL Server
  - Llevando a producción una tarjeta de sellos con NFC en Apple Wallet y Google Wallet
  - Editor de video con IA para Mac, Windows e iPhone
estudiando:
  - M.Sc. Ingeniería de Software (en curso)
  - M.Sc. Educación (en curso)
```
